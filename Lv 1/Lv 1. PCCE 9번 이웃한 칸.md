# [PCCE 기출문제] 9번 / 이웃한 칸 (프로그래머스 Lv.1)

## 문제 요약
- 칸마다 색 이름이 적힌 n×n 2차원 리스트 `board`와 고른 칸의 위치 `h`, `w`
- 고른 칸의 **상하좌우 4칸** 중 같은 색인 칸의 개수 반환
- 문제 설명에 **의사코드가 함께 제공됨**

> [!info] 유형
> 2차원 배열 + 방향 리스트(`dh`, `dw`) + 범위 검사
> **싸피 코테의 기본 뼈대** — [[Lv 0. 안전지대]](8방향), [[Lv 1. 공원 산책]]으로 이어짐

---

## 풀이 과정
- 문제에 주어진 의사코드를 한 단계씩 코드로 옮겨서 해결
- 스스로 진단: **의사코드가 없었다면 어려웠을 것**
  → "의사코드 → 코드 번역"은 되지만, **"문제 → 단계로 쪼개기(설계)"**가 약한 상태였음
- 이후 [[Lv 0. 안전지대]]에서 같은 구조를 **직접 설계**하는 연습으로 이어짐

---

## 내 코드 (통과)
```python
def solution(board, h, w):
    n = len(board)
    count = 0
    dh, dw = [0, 1, -1, 0], [1, 0, 0, -1]      # 오른쪽, 아래, 위, 왼쪽
    for i in range(0, 4, 1):
        h_check, w_check = h + dh[i], w + dw[i]
        if 0 <= h_check < n and 0 <= w_check < n:          # 범위 검사 (좌표 숫자!)
            if board[h][w] == board[h_check][w_check]:    # 값 비교
                count += 1
    return count
```

### 다듬은 버전 (참고)
```python
def solution(board, h, w):
    n = len(board)
    count = 0
    for dh, dw in [(0, 1), (1, 0), (-1, 0), (0, -1)]:   # 방향을 쌍으로
        nh, nw = h + dh, w + dw
        if 0 <= nh < n and 0 <= nw < n and board[nh][nw] == board[h][w]:
            count += 1
    return count
```
- `range(0, 4, 1)` → `range(4)`와 같음
- 방향을 **튜플 쌍**으로 묶으면 dh, dw 인덱스 짝 실수([[Lv 0. 캐릭터의_좌표]])를 막을 수 있음

### 복잡도
- 시간: **O(1)** (항상 4방향만 확인), 공간: **O(1)**

---

## 핵심 개념 정리

> [!important] 1. 값 vs 좌표가 한 코드에 같이 나옴
> - 범위 검사: `0 <= h_check < n` → **좌표 숫자**
> - 색 비교: `board[h_check][w_check]` → 그 위치의 **값**
> 이 코드가 "값 vs 좌표"의 정석 예시 → 헷갈릴 때 이 코드 다시 보기!

> [!important] 2. 4방향 리스트
> ```python
> dh, dw = [0, 1, -1, 0], [1, 0, 0, -1]
> ```
> 같은 인덱스 i끼리 한 쌍 (`dh[i]`, `dw[i]`)

> [!important] 3. 범위 검사를 먼저, 값 접근은 나중에
> 판 밖 좌표로 `board[...]`에 접근하면 에러 or 엉뚱한 칸(음수 인덱스)
