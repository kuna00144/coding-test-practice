## 1. 80분 시험 전략

| 시간 | 할 일 |
|---|---|
| 0 ~ 5분 | **두 문제 모두 훑어보기** (1번 제출 후에 2번이 열리는 방식일 수도 있으니 안내 확인) |
| 5 ~ 15분 | 1번 **입력 예시를 손으로 따라가기** → 한국어 의사코드 3~5줄 |
| 15 ~ 50분 | 1번 코드 작성 → 로컬에서 **입력 예시 전체**로 실행 → 제출 |
| 50 ~ 80분 | 2번: 정석 풀이가 안 보이면 **느려도 되는 완전탐색**으로 작은 케이스부터 |

> [!TIP]
> **막혔을 때 규칙**
> - 같은 줄에서 **15분** 넘게 막히면 → 종이에 작은 예시(3×3)를 그려서 손으로 다시 따라가기
> - 그래도 안 되면 → 지금까지 짠 걸 `print`로 찍어서 **어디서부터 값이 틀어지는지** 찾기
> - 문법이 기억 안 나면 → **for문과 if문만으로** 직접 구현 (느려도 정답이면 됨)

> [!IMPORTANT]
> **2번 부분 점수 전략**
> 숨겨진 테스트케이스가 있으므로, 부분 점수가 있다면 **작은 입력이라도 맞추는 게** 0점보다 훨씬 나음
> → 효율 생각하지 말고 **가능한 경우를 다 해보는 코드**부터 제출
> → 시간이 남으면 그때 개선

## 3. 내가 반복했던 실수 TOP 8

| # | 실수 | 기억법 | 나온 문제 |
|---|---|---|---|
| 1 | **값 vs 좌표** 혼동 | 범위 검사엔 `board[...]`가 **절대 안 나옴**. 오직 `nr, nc` | 안전지대, 공원 산책, 키패드, JadenCase |
| 2 | 범위 검사보다 **값을 먼저** 확인 | `범위 밖 or 장애물` → **범위가 항상 앞** | 공원 산책, 달팽이 숫자 |
| 3 | 순환을 **직접 공식**으로 | 돌아온다·반복된다 = **무조건 `%`** | 공 던지기, 모의고사, 달팽이 숫자 |
| 4 | **초기화 위치** 틀림 | 매번 새로 = 반복문 **안**, 계속 유지 = 반복문 **밖** | 파리 퇴치, 달팽이 숫자 |
| 5 | **공통 동작**을 분기마다 나눠 씀 | "모든 경우에 하는 일인가?" → if **앞이나 뒤에 한 번만** | RC카, 크레인 |
| 6 | 1부터 세는 번호 vs 0부터 인덱스 | 문제의 좌표 시작이 **0인지 1인지** 먼저 확인 | 가채점, 상하좌우, 크레인 |
| 7 | 행·열(x, y) 헷갈림 | 처음부터 **`r, c`** 로 이름 짓기. `board[r][c]` | 달팽이 숫자, 왕실의 나이트 |
| 8 | 작은 N에서 **우연히** 맞음 | N = 3만 보고 끝내지 말기 | 숫자 배열 회전 |

## 5. 문법 치트시트

### 2차원 리스트
```python
board = [[0] * M for _ in range(N)]     # ✅ N행 M열
board = [[0] * M] * N                   # ❌ 모든 행이 같은 리스트! 한 칸 바꾸면 전부 바뀜
copy_board = [row[:] for row in board]  # 2차원 복사 (그냥 = 은 복사가 아님)
```

> [!CAUTION]
> `[[0] * M] * N` 은 **절대 쓰지 말기**. 시험장에서 찾기 정말 어려운 버그

### 방향
```python
# 4방향: 상 우 하 좌 (시계 방향 순서)
dr = [-1, 0, 1, 0]
dc = [0, 1, 0, -1]

# 8방향
dr = [-1, -1, -1, 0, 0, 1, 1, 1]
dc = [-1, 0, 1, -1, 1, -1, 0, 1]

d = (d + 1) % 4     # 오른쪽으로 90도 회전 (시계)
d = (d + 3) % 4     # 왼쪽으로 90도 회전 (반시계)  — (d - 1) % 4 도 됨: 파이썬은 -1 % 4 → 3
d = (d + 2) % 4     # 뒤로 돌기
```

## 7. 구현 유형별 대처법

### ① 격자 이동 시뮬레이션 (로봇 청소기, 뱀, 캐릭터 이동)
- **상태 변수**를 정하기: 위치 `r, c` + 방향 `d` (+ 필요하면 시간, 점수)
- 매 단계: 다음 위치 계산 → 범위·벽·방문 검사 → 막히면 방향 전환 → 이동
- 방향 전환은 `%` ([[D2. 1954 달팽이 숫자]])
- **for문이 위치를 정하는 게 아니라 내가 위치를 들고 다님**

### ② 배열 회전 / 뒤집기
- 5번 문법의 회전 공식 사용
- **테두리만 회전**하는 문제 → 공식 대신 **값 하나를 임시 저장**하고 한 칸씩 밀기
  ```python
  temp = board[top][left]                 # 시작 값 저장
  # 왼쪽 열 위로 한 칸씩, 아래 줄 왼쪽으로, 오른쪽 열 아래로, 위 줄 오른쪽으로 밀기
  # 마지막 빈 자리에 temp
  ```

### ③ 부분 영역 합 / 최댓값 (파리 퇴치형)
- 시작점 개수 = `N - M + 1` → 범위 검사 불필요
- 실제 위치 = **시작점 + 상대 위치** `board[a + i][b + j]`

### ④ 주변 칸 세기 / 칠하기 (지뢰, 오목, 오셀로)
- 8방향 리스트 + 범위 검사
- 원본을 바꾸면서 읽으면 꼬임 → **결과용 판을 따로** ([[Lv 0. 안전지대]])
- 오목처럼 **한 방향으로 계속 가며 세기**:
  ```python
  cnt = 0
  nr, nc = r, c
  while 0 <= nr < N and 0 <= nc < N and board[nr][nc] == 'o':
      cnt += 1
      nr, nc = nr + dr[k], nc + dc[k]
  ```

### ⑤ 연속된 칸 세기 (단어 넣기, 최장 연속)
- 줄을 훑으며 `cnt += 1`, 끊기면 그 자리에서 판단 후 `cnt = 0`
- ⚠️ **줄 끝에서 끝나는 경우**를 반복문이 끝난 뒤 **한 번 더** 판단해야 함
  ```python
  for row in board:
      cnt = 0
      for v in row:
          if v == 1:
              cnt += 1
          else:
              if cnt == K: answer += 1
              cnt = 0
      if cnt == K: answer += 1        # ← 줄 끝 처리 (자주 빠뜨림!)
  ```
- 세로 방향은 `board[r][c]`에서 `r`과 `c` 반복 순서만 바꾸거나 `zip(*board)`로 전치

### ⑥ 중력 / 떨어뜨리기 (블록 게임)
- **열 단위로**, **아래에서부터** 빈칸이 아닌 값만 모아서 다시 아래부터 채우기
  ```python
  for c in range(M):
      stack = [board[r][c] for r in range(N) if board[r][c] != 0]   # 위→아래 순서로 모음
      for r in range(N - 1, -1, -1):
          board[r][c] = stack.pop() if stack else 0
  ```

### ⑦ 짝 맞추기 / 바로 앞과 비교 (괄호, 인형 뽑기)
- **스택**: 넣는 순간 `stack[-1]`과 비교 → 같으면 `pop`
- 빈 스택 체크 먼저 `if stack and stack[-1] == x:` ([[Lv 1. 크레인 인형뽑기 게임]])

### ⑧ 경우의 수를 다 해보기 (조합, 부분집합, 순서)
- `combinations`, `permutations`, `product` (5번 참고)
- 부분집합: `product([0, 1], repeat=N)` → 각 원소를 넣을지 말지
- 예: 재료 중 몇 개를 골라 칼로리 제한 안에서 최대 점수 → 모든 조합 시도

### ⑨ 영역 개수 / 최단 거리 (2번에 나올 가능성)
```python
from collections import deque

def bfs(sr, sc):
    q = deque([(sr, sc)])
    visited[sr][sc] = 1                         # 넣을 때 방문 표시!
    while q:
        r, c = q.popleft()
        for k in range(4):
            nr, nc = r + dr[k], c + dc[k]
            if 0 <= nr < N and 0 <= nc < M and board[nr][nc] == 갈수있는칸 and not visited[nr][nc]:
                visited[nr][nc] = visited[r][c] + 1    # 거리 = 이전 거리 + 1
                q.append((nr, nc))

# 최단 거리: bfs(시작) 후 visited[도착] - 1   (0이면 도달 불가)
# 영역 개수: 모든 칸을 돌며 아직 방문 안 한 갈 수 있는 칸에서 bfs 시작 → 시작할 때마다 +1
```
> [!IMPORTANT]
> - 방문 표시는 **큐에 넣을 때** (꺼낼 때 하면 중복으로 들어감)
> - `visited`는 **테스트케이스마다** 새로 만들기

### ⑩ 문자열 처리
- 회문 `s == s[::-1]`, 연속 공백 `split(" ")`, 알파벳 순서 `ord`
- 문자 하나씩 바꿀 땐 `list(s)`로 바꿔서 수정 후 `"".join(...)`
