# [SWEA D2] 1954. 달팽이 숫자 — 진행 중

> [!NOTE]
> 문제 원문과 입출력 예시는 SW Expert Academy 저작물이라 이 노트에 옮기지 않았습니다.
> 문제는 SWEA 사이트에서 **문제 번호 1954**로 검색해 확인하세요.

## 문제 핵심 (내 말로 한 줄)
- N×N 격자에 1부터 숫자를 **바깥에서 안쪽으로 시계 방향으로 돌면서** 채우기

## 유형
- 시뮬레이션 (위치와 방향을 직접 관리)
- 방향 전환 / 범위 검사 / 방문 체크
- [[Lv 1. 공원 산책]]의 "다음 위치 계산 → 검사 → 이동" + **방향 바꾸기**

---

## 1차 분석
- N을 입력받아야 함
- board를 만들어서 안을 전부 0으로 채움
- 이중 반복문 돌면서 `[i][j]` 형태로 숫자를 채워나감
- (0, 0)부터 시작해서 **벽을 만나거나 0이 아닌 값을 만나면** 가능한 방향을 체크해서 그쪽으로 이동

> [!TIP]
> 잘한 점
> - "0으로 채운 판 → (0, 0) 시작 → 벽 또는 이미 채운 칸에서 방향 전환"이라는 **핵심 규칙을 정확히 파악**
> - 0이 아닌 칸 = 이미 방문한 칸 → **값으로 방문 체크**하는 발상
> - 방향 리스트와 범위 검사를 바로 꺼내 씀

---

## 1차 코드 ❌
```python
T = int(input())

for test_case in range(1, T + 1):
    N = int(input())
    board = [[0] * N for _ in range(N)]
    di = [0, 0, -1, 1]
    dj = [1, -1, 0, 0]
    nb = 0
    for i in range(N):
        for j in range(N):
            for k in range(4):
                ni, nj = i + di[k], j + dj[k]
                if board[ni][nj] != 0 and 0 <= ni < N and 0 <= nj < N:
                    board[i][j] = nb

            nb += 1
    print(f"# {test_case} {board}")
```

## 피드백 (생각해볼 질문)

### 1. 이중 for문은 어떤 순서로 칸을 방문할까? ⭐ 가장 중요
- N = 3일 때 이중 for문의 방문 순서: (0,0) → (0,1) → (0,2) → (1,0) → (1,1) …
- 달팽이는 1, 2, 3을 첫 줄에 채운 뒤 **4는 어디에** 들어가야 할까?
- 이중 for문이 네 번째로 가는 (1,0)과 같은가?

> [!IMPORTANT]
> 이중 for문은 **항상 줄 단위**로 움직임 → 꺾어 도는 순서를 만들 수 없음
> → for문이 위치를 정하게 하지 말고, **"지금 위치"와 "지금 방향"을 변수로 들고 다니며** 한 칸씩 이동
> → [[Lv 1. 공원 산책]]에서 `H, W`를 변수로 두고 이동시킨 것과 같은 방식

**생각해볼 것:** 그럼 반복은 몇 번? 채워야 할 숫자가 1부터 몇까지인지?

### 2. 방향의 순서
- 달팽이 이동 순서: 오른쪽 → 아래 → 왼쪽 → 위 → 다시 오른쪽 …
- 지금 `di, dj` 순서: 오른쪽, 왼쪽, 위, 아래
- 방향을 바꿀 때 "다음 방향"으로 넘어가려면 리스트를 **도는 순서대로** 놓아야 함

**생각해볼 것:** 위(3번) 다음에 다시 오른쪽(0번)으로 돌아가는 계산은? → [[Lv 1. 모의고사]], [[Lv 0. 공 던지기]]에서 배운 연산자

### 3. 조건의 순서와 방향
- `board[ni][nj]`를 범위 검사보다 **먼저** 확인 → 판 밖 좌표로 접근해서 에러, 또는 음수 인덱스로 엉뚱한 칸을 읽음
- [[Lv 1. 공원 산책]]의 "범위 검사가 항상 먼저" (단락 평가)
- 방향을 바꿔야 하는 경우 = 범위 **밖**이거나 이미 **채워진** 칸
- 지금 조건은 그 **반대 상황**에서 칸을 채우고 있음

### 4. 출력 형식
- `f"# {test_case} {board}"` → `#` 뒤 공백 + 리스트가 대괄호 모양 그대로 출력됨
- 이 문제는 **번호 줄 다음에 격자를 줄마다** 출력하는 형태
- → [[SWEA 입출력 템플릿]]의 **출력 패턴 ③**

### 5. 시작 숫자
- 숫자는 0이 아니라 **1부터** 채워야 함

## 이번 문제의 핵심 감각
> [!IMPORTANT]
> **"for문이 위치를 정하는 게 아니라, 내가 위치를 들고 다닌다"**
> - 위치 변수 `(r, c)` + 방향 변수 `d`를 상태로 유지
> - 매 단계: 다음 위치 계산 → 검사 → (필요하면 방향 전환) → 이동
> - 이 틀이 잡히면 싸피 시뮬레이션 문제 대부분이 같은 구조로 풀림
