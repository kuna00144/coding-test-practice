# [SWEA D2] 2001. 파리 퇴치

> [!NOTE]
> 문제 원문과 입출력 예시는 SW Expert Academy 저작물이라 이 노트에 옮기지 않았습니다.
> 문제는 SWEA 사이트에서 **문제 번호 2001**로 검색해 확인하세요.

## 문제 핵심 (내 말로 한 줄)
- N×N 격자에서 **M×M 영역의 합이 가장 큰 값** 찾기

## 유형
- 완전탐색 (가능한 모든 위치를 다 확인)
- 2차원 배열 / 부분 영역의 합
- SWEA 입출력 (테스트케이스 T개)

---

## 내 분석
- T = 테스트케이스 수, 각 케이스마다 N과 M, 그다음 N×N 격자
- 파리채를 놓을 수 있는 **모든 위치**에서 합을 구하고 그중 최댓값
- CNN의 **맥스풀링**과 같은 구조라는 생각이 들었음
- 시작점이 (i, j)이고 M = 2라면 → `[i][j]`, `[i][j+1]`, `[i+1][j]`, `[i+1][j+1]`
- M이 커지면? → M×M을 도는 반복문이 따로 필요
- 직접 세어본 반복 횟수 (N = 5일 때)

| M | 반복 횟수 | 한 줄당 시작 위치 |
|---|---|---|
| 2 | 16 | 4 |
| 3 | 9 | 3 |
| 4 | 4 | 2 |

> [!TIP]
> 이 표에서 **한 줄당 시작 위치 = N − M + 1** 이라는 규칙을 찾아냄 → 이 문제의 핵심

---

## 풀이 과정

### 1차 막힘: 시작 위치를 어떻게 옮기지?
```python
for i in range(M):
    for j in range(M):
        score += board[i][j]      # 항상 (0, 0)부터만 더함
```
- M×M 합은 구했지만 **시작점을 옮기는 방법**을 몰라서 막힘
- 합계와 최댓값을 `score` 하나로 같이 관리하려 함

### 받은 힌트 (질문 형태)
1. 직접 센 4, 3, 2를 N과 M으로 만드는 **하나의 식**은? → `N - M + 1`
2. 시작점 (1, 2)에서 파리채 안의 (0, 1)은 판 전체로 어디? → `(1 + 0, 2 + 1)`
3. 합계(위치마다 0부터)와 최댓값(케이스마다 0부터)을 **분리**하기

### 2차: 로직 완성, 그런데 런타임 에러
- 로직은 전부 정답
- 그런데 SWEA에서 **"Memory error occurred"** 메시지
- 실제 원인: `input.split()` → `input().split()` (괄호 하나 빠짐)

> [!WARNING]
> **SWEA 에러 메시지는 실제 원인과 다를 수 있음**
> 단순한 문법 에러도 "Memory error"처럼 뭉뚱그려 보여줌
> → 메시지만 믿고 메모리·시간 문제를 찾으면 시간 낭비
> → **PyCharm에서 먼저 실행**하면 정확한 줄과 원인을 알려줌

### 3차 → 성공 🎉

## 최종 코드
```python
# import sys
# sys.stdin = open("input.txt", "r")   # 로컬 테스트용 — 제출 전 주석 처리!

T = int(input())

for test_case in range(1, T + 1):
    N, M = map(int, input().split())
    board = [list(map(int, input().split())) for _ in range(N)]
    N_in_M = N - M + 1          # 한 줄에서 파리채를 놓을 수 있는 시작 위치 개수
    max_score = 0               # 테스트케이스마다 한 번 초기화

    for a in range(N_in_M):         # 시작 행
        for b in range(N_in_M):     # 시작 열
            score = 0               # 시작 위치마다 새로 초기화

            # M x M 영역의 합
            for i in range(M):
                for j in range(M):
                    score += board[i + a][j + b]    # 시작점 + 파리채 안 위치

            if max_score < score:
                max_score = score

    print(f"#{test_case} {max_score}")
```

### 복잡도
- 시간: **O((N − M + 1)² × M²)** → N ≤ 15라 충분히 빠름
- 공간: **O(N²)** (격자 저장)

## 다듬은 버전 (참고)
```python
T = int(input())
for test_case in range(1, T + 1):
    N, M = map(int, input().split())
    board = [list(map(int, input().split())) for _ in range(N)]

    max_score = 0
    for a in range(N - M + 1):
        for b in range(N - M + 1):
            score = sum(board[a + i][b + j] for i in range(M) for j in range(M))
            max_score = max(max_score, score)

    print(f"#{test_case} {max_score}")
```
- 안쪽 이중 반복문을 `sum()` 한 줄로
- 최댓값 갱신을 `max()`로 → [[Lv 1. 최소직사각형]]의 갱신 패턴과 같음
- 지금 코드도 충분히 좋은 풀이! 시험에선 **읽기 쉬운 쪽**을 고르면 됨

### (심화) 더 빠르게: 2차원 누적합
N이 매우 크다면 M×M 합을 매번 다시 더하는 게 느려짐
→ **2차원 누적합**을 미리 만들어두면 각 영역의 합을 O(1)에 구할 수 있음
→ 지금 문제 크기에선 필요 없지만, 나중에 D3~D4에서 다시 만날 개념

## 핵심 개념 정리

> [!IMPORTANT]
> **1. 시작 위치 개수 = N − M + 1**
> 크기 N인 줄에 길이 M짜리를 놓을 수 있는 시작점 개수
> `range(N - M + 1)`로 돌면 **범위 밖으로 나갈 일이 애초에 없음** → 범위 검사 불필요

> [!IMPORTANT]
> **2. 시작점 + 상대 위치 = 실제 위치**
> `board[a + i][b + j]`
> - `(a, b)` = 파리채의 시작점 (판 전체 기준)
> - `(i, j)` = 파리채 안에서의 위치 (0 ~ M−1)
> - 처음 생각한 `[i][j+1]`, `[i+1][j]`를 M 크기에 상관없이 **일반화**한 것

> [!IMPORTANT]
> **3. 초기화 위치가 곧 의미**
> - `max_score = 0` → `for test_case` 안 → 케이스마다 새로
> - `score = 0` → `for b` 안 → 시작 위치마다 새로
> - 변수를 **어느 반복문 안에서 초기화하느냐**가 그 변수의 범위를 결정

> [!IMPORTANT]
> **4. 직접 세어보면 규칙이 보인다**
> 16 → 9 → 4를 세어본 것에서 `N − M + 1`을 발견
> 막히면 **작은 숫자로 직접 세어보기**

## 틀렸던 부분 한눈에 보기

| 실수 | 왜 틀렸나 | 바른 방법 |
|---|---|---|
| `board[i][j]`만 더함 | 항상 (0, 0)에서 시작 | `board[a + i][b + j]` |
| 합계와 최댓값을 한 변수로 | 위치마다 리셋할 값과 유지할 값이 섞임 | `score`, `max_score` 분리 |
| `input.split()` | `input` 함수를 호출 안 함 | `input().split()` |
| SWEA 에러 메시지를 그대로 믿음 | 원인과 다른 메시지가 나옴 | 로컬에서 먼저 실행 |
