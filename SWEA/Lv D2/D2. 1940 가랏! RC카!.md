# [SWEA D2] 1940. 가랏! RC카!

> [!NOTE]
> 문제 원문과 입출력 예시는 SW Expert Academy 저작물이라 이 노트에 옮기지 않았습니다.
> 문제는 SWEA 사이트에서 **문제 번호 1940**으로 검색해 확인하세요.

## 문제 핵심 (내 말로 한 줄)
- 매초 주어지는 명령(유지 / 가속 / 감속)에 따라 **속도를 바꾸고**, 그 속도만큼 **거리를 누적**해서 총 이동 거리 구하기

## 유형
- 구현 / **상태 시뮬레이션** (속도와 거리를 들고 다니기)
- **줄마다 개수가 다른 입력** 처리

---

## 문제 이해 과정 (코드 전에 한 질문)

### 질문 1. 시간과 N은 관련이 없는가?
> [!TIP]
> **N이 곧 시간**
> - 명령 하나 = 1초 → 명령 N개 = N초
> - 시간 변수를 따로 만들 필요 없이 **반복 한 번 = 1초**
> - 문제의 시간 표는 이해를 돕는 설명용일 뿐, 입력으로 주어지지 않음

### 질문 2. 왜 이 입력이 4가 되는가?
```text
1 1
0
1 1
```

| 시간 | 명령 | 속도 변화 | 그 초의 속도 | 이번 초 거리 | 누적 거리 |
|---|---|---|---|---|---|
| 1초 | 가속 1 | 0 + 1 | 1 | 1 | **1** |
| 2초 | 유지 | 그대로 | 1 | 1 | **2** |
| 3초 | 가속 1 | 1 + 1 | 2 | 2 | **4** |

> [!IMPORTANT]
> 헷갈렸던 두 지점
> 1. **유지(0)는 멈춤이 아님** → 이전 속도 그대로 계속 이동
> 2. **가속은 속도를 설정하는 게 아니라 더하는 것** → 이전 속도 + 가속도

> [!TIP]
> 잘한 점
> - 코드를 짜기 전에 **문제를 이해하지 못한 부분을 정확히 질문**함
> - 질문 후에는 **힌트 없이 코드를 혼자 완성**

## 내 코드 (통과)
```python
# import sys
# sys.stdin = open("input.txt", "r")   # 로컬 테스트용 — 제출 전 주석 처리!

T = int(input())

for test_case in range(1, T + 1):
    N = int(input())
    total = 0                          # 누적 거리 (케이스마다 초기화)
    time, speed = 0, 0                 # 현재 속도 (케이스마다 초기화)
    for _ in range(N):                 # 반복 한 번 = 1초
        a = list(map(int, input().split()))
        if len(a) == 1:                # 명령 0: 유지
            total += speed
        elif len(a) == 2:              # 명령 1 또는 2: 가속도 값이 함께 옴
            time, f_speed = a[0], a[1]
            if time == 1:              # 가속
                speed += f_speed
                total += speed
            elif time == 2:            # 감속
                if speed < f_speed:
                    speed = 0          # 속도는 0 아래로 내려가지 않음
                else:
                    speed -= f_speed
                    total += speed
    print(f"#{test_case}", total)
```

> [!TIP]
> 잘한 점
> - **줄마다 개수가 다른 입력**을 리스트로 받아 `len(a)`로 구분 → 깔끔한 처리
> - 속도·거리를 **케이스마다 초기화** ([[D2. 2001 파리 퇴치]] "초기화 위치가 곧 의미")
> - 감속 시 속도가 음수가 되지 않도록 처리 (제약사항 반영)
> - 감속으로 속도가 0이 되면 거리를 안 더하지만, 어차피 0을 더하는 것이라 결과 동일 ✅

### 복잡도
- 시간: **O(N)** (테스트케이스당), 공간: **O(1)**

## 다듬은 버전 (참고)
```python
T = int(input())
for test_case in range(1, T + 1):
    N = int(input())
    speed = distance = 0
    for _ in range(N):
        cmd = list(map(int, input().split()))
        if cmd[0] == 1:                          # 가속
            speed += cmd[1]
        elif cmd[0] == 2:                        # 감속
            speed = max(0, speed - cmd[1])
        distance += speed                        # 매초 공통: 현재 속도만큼 이동

    print(f"#{test_case} {distance}")
```
바뀐 점:
- **"속도 바꾸기"와 "거리 더하기"를 분리** → `total += speed`가 네 군데에서 **한 곳**으로
  - 명령이 무엇이든 매초 마지막엔 항상 현재 속도만큼 이동 → 공통 동작은 밖으로
  - [[실전. 왕실의 나이트]]의 다듬은 버전, [[Lv 1. 키패드 누르기]]의 "결정과 실행 분리"와 같은 원리
- 감속: `max(0, speed - 감속도)` → if-else 없이 "0 아래로 안 내려가기"를 한 줄로
- 명령 구분을 `len(cmd)` 대신 **`cmd[0]` 값**으로 → 명령의 의미가 코드에 드러남
- 변수 이름 `time` → 실제로는 명령 번호라 `cmd`가 더 정확 (`time`은 시간처럼 읽혀 헷갈림)

## 핵심 개념 정리

> [!IMPORTANT]
> **1. 상태 시뮬레이션**
> 상태(속도)를 들고 다니며 매 단계 **상태 갱신 → 결과 누적**
> [[D2. 1954 달팽이 숫자]]는 위치·방향, 이 문제는 속도가 상태

> [!IMPORTANT]
> **2. 공통 동작은 분기 밖으로**
> 모든 경우에 똑같이 하는 일(거리 누적)이 if마다 반복되면 → **분기 뒤에 한 번만**
> 실수(어느 한 분기에서 빠뜨리기)를 원천 차단

> [!IMPORTANT]
> **3. 줄마다 개수가 다른 입력**
> ```python
> cmd = list(map(int, input().split()))   # "0" → [0], "1 2" → [1, 2]
> ```
> 리스트로 받은 뒤 첫 값이나 길이로 구분

> [!IMPORTANT]
> **4. 하한 처리는 `max`, 상한 처리는 `min`**
> - 0 아래로 내려가지 않게: `max(0, 값)`
> - 어떤 값을 넘지 않게: `min(상한, 값)`

> [!IMPORTANT]
> **5. 문제가 이해 안 되면 예제를 표로 따라가기**
> 시간 / 명령 / 속도 / 거리를 표로 한 줄씩 → 규칙이 바로 보임
