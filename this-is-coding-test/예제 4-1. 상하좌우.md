# [이코테] 예제 4-1. 상하좌우

> [!NOTE]
> 문제 원문과 입출력 예시는 도서 저작물이라 이 노트에 옮기지 않았습니다.
> 문제는 책 **Chapter 4 구현, 예제 4-1**에서 확인하세요.

## 문제 핵심 (내 말로 한 줄)
- N×N 공간의 **(1, 1)**에서 출발해 L·R·U·D 이동 계획대로 움직이되, **공간 밖으로 나가는 이동은 무시**하고 최종 좌표 출력

## 유형
- 구현 / 시뮬레이션
- 방향 이동 + 범위 검사 → **"다음 위치 계산 → 검사 → 이동"** 패턴

---

## 내 코드 (해설 보기 전, 한 번에 통과)
```python
N = int(input())
n_move = list(map(str, input().split()))
move = {"L": (0, -1), "R": (0, 1), "U": (-1, 0), "D": (1, 0)}
x, y = 1, 1

for m in n_move:
    nx, ny = x + move.get(m)[0], y + move.get(m)[1]   # 다음 위치 계산
    if 1 <= nx <= N and 1 <= ny <= N:                  # 공간 안이면
        x, y = nx, ny                                  # 이동

print(x, y)
```

> [!TIP]
> 잘한 점
> - **힌트 없이, 해설도 안 보고 한 번에** 풀이
> - 방향을 **딕셔너리**로 키 → 이동량 바로 연결 ([[Lv 0. 캐릭터의_좌표]]에서 배운 방식)
> - 좌표가 **1부터** 시작한다는 점을 놓치지 않고 범위를 `1 <= nx <= N`으로 설정
> - "다음 위치 계산 → 범위 검사 → 이동" 패턴이 손에 붙음

---

## 책 해설 코드
> 출처: 나동빈, 『이것이 취업을 위한 코딩 테스트다 with 파이썬』, 예제 4-1
> 저자 GitHub: `ndb796/python-for-coding-test`

```python
# N 입력받기
n = int(input())
x, y = 1, 1
plans = input().split()

# L, R, U, D에 따른 이동 방향
dx = [0, 0, -1, 1]
dy = [-1, 1, 0, 0]
move_types = ['L', 'R', 'U', 'D']

# 이동 계획을 하나씩 확인
for plan in plans:
    # 이동 후 좌표 구하기
    for i in range(len(move_types)):
        if plan == move_types[i]:
            nx = x + dx[i]
            ny = y + dy[i]
    # 공간을 벗어나는 경우 무시
    if nx < 1 or ny < 1 or nx > n or ny > n:
        continue
    # 이동 수행
    x, y = nx, ny

print(x, y)
```

---

## 내 코드 vs 해설 비교

| 항목 | 내 코드 | 해설 |
|---|---|---|
| 방향 저장 | 딕셔너리 `{"L": (0, -1), ...}` | 리스트 3개 (`dx`, `dy`, `move_types`) |
| 방향 찾기 | `move[m]`로 **바로** 꺼냄 | `move_types`를 for문으로 돌며 **일치하는 것 찾기** |
| 범위 검사 | 범위 **안**이면 이동 (`and`) | 범위 **밖**이면 `continue` (`or`) |
| 결과 | 동일 ✅ | 동일 ✅ |

> [!NOTE]
> 두 범위 검사는 **같은 뜻**
> - 안이면 이동: `1 <= nx <= N and 1 <= ny <= N`
> - 밖이면 건너뛰기: `nx < 1 or ny < 1 or nx > N or ny > N` → `continue`
> - "안"의 `and`를 뒤집으면 "밖"의 `or` (드모르간 법칙, [[Lv 1. PCCE 9번 지폐 접기]] 참고)

## 다듬은 버전 (참고)
```python
N = int(input())
plans = input().split()                 # split()은 이미 문자열 리스트
move = {"L": (0, -1), "R": (0, 1), "U": (-1, 0), "D": (1, 0)}
x, y = 1, 1

for m in plans:
    dx, dy = move[m]                    # 한 번 꺼내서 나눠 담기
    nx, ny = x + dx, y + dy
    if 1 <= nx <= N and 1 <= ny <= N:
        x, y = nx, ny

print(x, y)
```
- `list(map(str, input().split()))` → `input().split()`만으로 충분
- `move.get(m)`을 두 번 부르는 대신 `dx, dy = move[m]` 한 번으로 (튜플 언패킹)

### 복잡도
- 시간: **O(K)** (K = 이동 계획 개수), 공간: **O(K)**

## 핵심 개념 정리

> [!IMPORTANT]
> **1. 다음 위치 계산 → 검사 → 이동**
> ```python
> nx, ny = x + dx, y + dy
> if 범위 안:
>     x, y = nx, ny
> ```
> [[Lv 0. 캐릭터의_좌표]], [[Lv 1. 공원 산책]], [[D2. 1954 달팽이 숫자]]와 같은 뼈대

> [!IMPORTANT]
> **2. 좌표 시작점 확인**
> 이 문제는 **(1, 1)부터** → 범위가 `1 ~ N`
> 리스트 인덱스(0부터)를 쓰는 문제는 `0 ~ N-1` → 문제마다 꼭 확인

> [!IMPORTANT]
> **3. 문자 방향 → 딕셔너리**
> 방향이 `"L"`, `"R"` 같은 **문자**로 주어지면 딕셔너리가 가장 간단
> 모든 방향을 다 돌아야 하면 `dx`, `dy` 리스트
