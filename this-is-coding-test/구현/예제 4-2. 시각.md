# [이코테] 예제 4-2. 시각

> [!NOTE]
> 문제 원문과 입출력 예시는 도서 저작물이라 이 노트에 옮기지 않았습니다.
> 문제는 책 **Chapter 4 구현, 예제 4-2**에서 확인하세요.

## 문제 핵심 (내 말로 한 줄)
- 00시 00분 00초부터 N시 59분 59초까지, 시·분·초 어딘가에 **숫자 3이 하나라도 들어간** 시각의 개수 세기

## 유형
- 구현 / **완전탐색** (모든 시각을 하나씩 확인)
- 문자열로 바꿔서 포함 여부 확인

---

## 내 코드 (해설 보기 전, 한 번에 통과)
```python
N = int(input())
count = 0
for i in range(N + 1):          # 시: 0 ~ N
    for j in range(60):         # 분: 0 ~ 59
        for k in range(60):     # 초: 0 ~ 59
            if '3' in str(i) + str(j) + str(k):   # 시·분·초를 이어 붙인 문자열에 '3'이 있으면
                count += 1

print(count)
```

> [!TIP]
> 잘한 점
> - **힌트 없이, 해설도 안 보고 한 번에** 풀이 → 책 해설 코드와 **동일한 방식**
> - `range(N + 1)`로 **N시까지 포함**
> - 시·분·초를 **문자열로 이어 붙여** `'3' in ...` 한 번으로 확인 → 자리마다 따로 검사할 필요 없음
> - 경우의 수가 작아서 **다 세어봐도 된다**는 판단

---

## 왜 완전탐색이 가능한가
- 하루 전체 시각 = 24 × 60 × 60 = **86,400개**
- 이 정도는 전부 확인해도 순식간 → 규칙을 찾을 필요 없이 **다 세면 됨**

> [!IMPORTANT]
> **완전탐색 판단 기준**
> 전체 경우의 수가 대략 **100만 개 이하**면 하나씩 다 확인해도 시간 안에 충분
> → 먼저 "몇 가지 경우가 있지?"를 계산해보기

### 복잡도
- 시간: **O(N × 3600)** → 최대 약 86,400번
- 공간: **O(1)**

---

## 핵심 개념 정리

> [!IMPORTANT]
> **1. 숫자 포함 여부는 문자열로**
> ```python
> '3' in str(13)        # True
> '3' in "1" + "5" + "30"   # True
> ```
> 숫자를 자리마다 `% 10`, `// 10`으로 쪼개는 것보다 훨씬 간단

> [!IMPORTANT]
> **2. 중첩 for문 = 모든 조합**
> 시 × 분 × 초를 3중 for문으로 돌면 가능한 시각을 **빠짐없이** 한 번씩 방문

> [!IMPORTANT]
> **3. 범위 끝 포함 여부**
> - 시: 0 ~ N → `range(N + 1)`
> - 분·초: 0 ~ 59 → `range(60)`
> `range`는 **끝 숫자를 포함하지 않음** → 포함하려면 +1
