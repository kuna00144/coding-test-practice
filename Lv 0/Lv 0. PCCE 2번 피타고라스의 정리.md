# [PCCE 기출문제] 2번 / 피타고라스의 정리 (프로그래머스 Lv.0)

## 문제 요약
- 직각삼각형의 한 변 `a`와 빗변 `c`가 입력으로 주어짐
- 나머지 한 변의 **제곱** `b_square`를 출력하도록 코드 **한 줄을 고치기**
- 공식: `a² + b² = c²` → `b² = c² - a²`

> [!info] 유형
> 한 줄 수정(디버깅) / 표준 입력 / 거듭제곱 연산

---

## 내 코드 (통과)
```python
a = int(input())
c = int(input())

b_square = c**2 - a**2
print(b_square)
```

---

## 핵심 개념 정리

> [!important] 1. 거듭제곱 연산자 `**`
> - `c**2` → c의 제곱
> - `^`는 파이썬에서 거듭제곱이 **아님** (비트 XOR 연산) → 자주 하는 실수!

> [!important] 2. 표준 입력 (SWEA·백준 형식)
> ```python
> a = int(input())   # 한 줄에 숫자 하나 읽기
> ```
> 프로그래머스 함수형과 달리 **직접 입력을 받는 형식** → 싸피 시험(SWEA 스타일)과 같은 방식

> [!important] 3. "한 줄 수정" 문제 푸는 법
> 코드 전체를 새로 짜지 말고, **입출력 예시를 손으로 따라가면서** 어느 줄에서 결과가 어긋나는지 찾기
