# 최소직사각형 (프로그래머스 Lv.1)

## 문제 요약
- 명함들의 `[가로, 세로]` 크기가 담긴 2차원 리스트 `sizes`
- 명함은 **눕혀서(90도 회전)** 넣을 수 있음
- 모든 명함을 넣을 수 있는 **가장 작은 지갑의 넓이** 반환

> [!info] 유형
> 완전탐색 / **회전 가능 = 긴 변끼리, 짧은 변끼리 비교** / max-min
> [[Lv 1. PCCE 9번 지폐 접기]]의 "90도 회전" 아이디어와 같은 원리

---

## 1차 분석 (혼자 설계)
- 2차원 배열이라 `sizes`에서 값을 읽어올 때 잘 체크해야 함
- w와 h 중 **한쪽으로 큰 숫자가 오도록** 전부 정렬
- w 쪽에 큰 숫자가 다 모였다고 가정하면 → **w의 최댓값 × h의 최댓값** = 모든 명함이 들어가는 가장 작은 지갑
- 어떻게 한쪽으로 몰지? → 반복문마다 w, h를 비교해서 **큰 걸 w 쪽으로**

> [!success] 잘한 점
> - **분석부터 코드까지 힌트 없이 혼자** 완성, 한 번에 통과
> - 핵심 아이디어("한쪽으로 몰고 각각 최댓값")를 스스로 도출
> - [[Lv 1. PCCE 9번 지폐 접기]]에서 AI 도움으로 접했던 **회전 개념**을 이번엔 스스로 떠올림
> - `>=`로 가로세로가 같은 명함까지 처리 → 엣지 케이스 OK

## 최종 코드 (통과) 🎉
```python
def solution(sizes):
    w_list, h_list = [], []
    for i in range(len(sizes)):
        if sizes[i][0] >= sizes[i][1]:     # 가로가 더 길면 그대로
            w_list.append(sizes[i][0])
            h_list.append(sizes[i][1])
        else:                              # 세로가 더 길면 돌려서
            w_list.append(sizes[i][1])
            h_list.append(sizes[i][0])

    answer = max(w_list) * max(h_list)     # 긴 변 최댓값 × 짧은 변 최댓값
    return answer
```

### 복잡도
- 시간: **O(N)**, 공간: **O(N)** (리스트 2개)

## 다듬은 버전 (참고)
```python
def solution(sizes):
    max_w, max_h = 0, 0
    for w, h in sizes:                      # 언패킹으로 바로 꺼내기
        max_w = max(max_w, max(w, h))       # 긴 변 중 최댓값
        max_h = max(max_h, min(w, h))       # 짧은 변 중 최댓값
    return max_w * max_h
```
바뀐 점:
- `for w, h in sizes` → `sizes[i][0]` 같은 인덱스 없이 바로 꺼냄 (읽기 쉬움)
- 리스트에 다 모으지 않고 **지금까지의 최댓값만 기억** → 공간 **O(1)**
- if-else 분기를 `max(w, h)`, `min(w, h)`로 대신 → "긴 변끼리, 짧은 변끼리"가 코드에 그대로 드러남

## 핵심 개념 정리

> [!important] 1. 회전 가능 = 긴 변끼리, 짧은 변끼리
> 돌릴 수 있다는 건 방향이 상관없다는 뜻
> → 각 명함을 `(긴 변, 짧은 변)`으로 통일해서 비교
> [[Lv 1. PCCE 9번 지폐 접기]]와 같은 원리

> [!important] 2. 2차원 리스트 언패킹
> ```python
> for w, h in sizes:     # sizes = [[60, 50], [30, 70], ...]
> ```
> 각 원소가 2개짜리 리스트면 바로 두 변수에 나눠 담을 수 있음

> [!important] 3. 최댓값은 모아두지 않고 갱신하기
> ```python
> best = 0
> for x in data:
>     best = max(best, x)
> ```
> 리스트에 다 넣고 마지막에 `max()` → 공간 O(N)
> 반복하면서 갱신 → 공간 O(1)

> [!important] 4. 정렬 기준을 통일하면 문제가 단순해진다
> 경우마다 회전할지 말지 따지는 대신, **모두 같은 기준(긴 변을 앞으로)으로 맞춘 뒤** 계산
> → 완전탐색처럼 보이는 문제가 한 번의 순회로 끝남
